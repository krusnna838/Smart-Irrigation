# 🌱 AgriSense AI – Smart Irrigation Management System

AgriSense AI is an AI-powered Smart Irrigation System developed using Python, Flask, Machine Learning, and Groq AI. The system helps farmers and agricultural professionals determine the optimal irrigation requirements based on environmental and soil conditions.

## 🚀 Features

### 🌾 Smart Irrigation Prediction
- Predicts water requirements using Machine Learning.
- Uses soil moisture, temperature, humidity, and rainfall data.
- Provides irrigation volume recommendations in liters.

### 🤖 AI-Powered Analysis
- Integrates Groq Llama 3.3 AI model.
- Generates professional irrigation insights.
- Provides water-saving recommendations.

### 📊 Analytics Dashboard
- Displays irrigation status.
- Shows AI-generated field analysis.
- Helps improve irrigation efficiency.

### 📁 History Management
- Stores prediction records automatically.
- View recent irrigation logs.
- Download prediction history as CSV.

### 📄 Report Generation
- Generate AI-based PDF reports.
- Download detailed irrigation analysis.
- Export AI recommendations.
